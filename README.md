# Orbi

Orbi keeps your coding agents at the edge of your screen. Install it through your desktop AI agent:

```text
Install Orbi for me by following https://orbi.chrystalesia.com/install.md
```

Your agent detects your system, downloads the correct files from Cloudflare R2, verifies their checksums, installs Orbi and connects your agents. No GitHub account is needed for installation.

[Website](https://orbi.chrystalesia.com/) ? [Setup help](https://orbi.chrystalesia.com/support.html) ? [Report an issue](https://github.com/RaflyLesmana3003/orbi-releases/issues)

This repository is kept for support issues and existing documentation links. Development source is private. Release packages and version metadata are hosted on Cloudflare R2; GitHub Releases are no longer used.

The [installation guide](https://orbi.chrystalesia.com/install.md), [bridge reference](https://orbi.chrystalesia.com/bridge.md), [tool reference](https://orbi.chrystalesia.com/tools.md), and [agent instruction block](https://orbi.chrystalesia.com/agent-instructions.md) are available on the website.
